# Site de divulgação científica — Conectividade de Paisagens do Cerrado

Site estático com cinco páginas, pronto para GitHub Pages. Os textos e nomes são demonstrativos.

## Publicação
1. Crie um repositório público no GitHub, por exemplo `site-conectividade`.
2. Envie **o conteúdo desta pasta** para a raiz do repositório (index.html, demais HTML e pastas css, js etc.).
3. Vá a Settings > Pages > Build and deployment. Escolha Deploy from a branch, branch main, pasta /(root) e Save.
4. Acesse `https://SEU-USUARIO.github.io/site-conectividade/` depois que a implantação terminar.

## Edição
- Edite os arquivos .html diretamente no GitHub (ícone de lápis e Commit changes).
- CSS em `css/estilo.css`.
- Artigos, mapas e produtos estão com textos de exemplo.
- Para mapas reais, exporte dados do QGIS como GeoJSON e integre ao Leaflet/qgis2web em uma próxima etapa.
- Antes de publicar PDFs de artigos, confira a política de direitos da revista.
